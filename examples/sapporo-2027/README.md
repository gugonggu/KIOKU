# 삿포로 2027 · 가상 검증 자료

화면과 입력 흐름을 검증하는 4박 5일 가상 여행입니다. 2027-02-10~14와 동행 3명을 사용합니다.

- `itinerary.json`을 **일정 → JSON 일정 가져오기**에서 열어 미리보고 저장합니다. 27개 중 날짜가 없는 4개는 후보함으로 이동합니다.
- `places.json`, `bookings.json`, `checklist.json`, `budget.json`은 해당 화면에서 수동으로 입력하는 참고 자료입니다. 연결할 장소는 장소 등록 후 일정 편집에서 선택합니다.
- 시간은 일본 현지 `HH:mm`입니다. 확정 항공 시각은 예약 화면에 공항별 시간대와 함께 입력합니다. `time`과 `period`는 한 행에 함께 쓸 수 없습니다.
