# KIOKU · 記憶 제품 범위

2026-11-26 제품 소유자 결정 · v1.1

일본 여행을 계획하고, 함께 떠나고, 소중한 기억을 남기는 디지털 여행 수첩.

A travel journal for planning, exploring, and remembering Japan.

| 경험 | 유지하는 기능 |
| --- | --- |
| PLAN · 여행 준비 | 여행 생성·선택·편집·삭제, 기간·지역·인원, 표지, D-day, 날짜별·전체 일정, 시작·종료 시각과 소요 시간, 시간대·미정 일정, 후보·순서·복사·이동·JSON 가져오기, 장소·예약 연결, 항공·숙소·투어 일정과 상태, 소유자 전용 예약 상세·가격·통화, 체크리스트·템플릿·진행률 |

예산·경비 원장, 지출 및 환불, 환율과 환산, 결제자·정산 참여자·분담·송금, 경비 분류·통계와 예약 금액 복사는 v1.1 사용자 기능에서 제외한다. 예약 가격과 통화는 예약 계획의 일부로 소유자 상세에 유지한다. 공유·PDF·오프라인은 기존 허용 필드 범위를 유지한다.

기존 경비 테이블, 데이터, 적용 migration과 권한은 보존한다. v1.1 앱은 경비 테이블을 조회하거나 수정하지 않는다. 기존 여행 삭제의 데이터 관계는 유지한다. 장기 보존, 내보내기, 접근 종료, 폐기는 별도 승인과 검토가 필요하다.

기능 제안은 PLAN·TRAVEL·REMEMBER 중 어느 경험을 직접 돕는지, 기존 기능과 중복되는지, 유지 비용과 개인정보 영향이 가치에 비례하는지 검토한다. 변경 효과와 검증 방법을 기록하고 제품 소유자 승인을 받은 뒤 핵심 범위를 변경한다. 이 결정은 경비 기능과 충돌하는 이전 기획·검증 기록보다 우선한다.
